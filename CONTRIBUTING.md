## Contributor License Agreement (CLA)

Before any pull request that adds or modifies source code can be merged,
the contributor must execute a Contributor License Agreement (CLA) that
grants the copyright holder the right to dual-license the contribution
under both AGPLv3 and the proprietary Commercial License.

Until the CLA is signed and recorded:

- External pull requests that touch licensed source will be closed.
- Issues and discussion are welcome.

Contact the maintainer to receive the CLA form.

## Scope of this repository

This repository is the χ commitment primitive only. Do not open PRs that:

- inject ranking, sorting, or residual logic into the core;
- change the irreversible-selection identity of χ;
- add forecasts or trading claims.

See the LIC-001 implementation plan for the license chassis rules.
